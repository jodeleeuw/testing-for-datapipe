DataPipe Test Page

Test data uploads and trigger errors to verify logging in the DataPipe system.

Server: Production https://pipe.jspsych.org

Success Tests

Valid CSV Upload

Sends a valid CSV file with a unique filename.

Valid JSON Upload

Sends valid JSON data with a unique filename.

Error Tests

Missing Parameters

Sends request with no data or filename. Expected: MISSING_PARAMETER

Invalid Experiment ID

Sends data with a fake experiment ID. Expected: EXPERIMENT_NOT_FOUND

Duplicate Filename

Sends the same filename twice. Expected: OSF_FILE_EXISTS on second attempt

Empty Data Field

Sends an empty string as data. Expected: MISSING_PARAMETER

Invalid Base64 Upload

Sends non-base64 data to the base64 endpoint. Expected: INVALID_BASE64_DATA

Valid Base64 Upload

Sends a small valid base64 image to the base64 endpoint.
