DataPipe Test Page

Test data uploads and trigger errors to verify logging in the DataPipe system.

Server: Production https://pipe.jspsych.org

Success Tests

Valid CSV Upload

Sends a valid CSV file with a unique filename.

Valid JSON Upload

Sends valid JSON data with a unique filename.

Valid Base64 Upload

Sends a small valid base64 image to the base64 endpoint.

Plugin: Save CSV

Runs a 1-trial jsPsych experiment and pipes the CSV results via the plugin.

Plugin: Save JSON

Runs a 1-trial jsPsych experiment and pipes the JSON results via the plugin.

Error Tests

Missing Parameters

Sends request with no data or filename. Expected: MISSING_PARAMETER

Invalid Experiment ID

Sends data with a fake experiment ID. Expected: EXPERIMENT_NOT_FOUND

Duplicate Filename

Sends the same filename twice. Expected: OSF_FILE_EXISTS on second attempt

Empty Data Field

Sends an empty string as data. Expected: MISSING_PARAMETER

Invalid Base64 Upload

Sends non-base64 data to the base64 endpoint. Expected: INVALID_BASE64_DATA

Upload Queue Tests (PR #142)

Uses the experiment ID above. Before running, add some dummy characters to the experiment's osfFilesLink in Firestore to make the OSF upload fail. Expected response: HTTP 202 with OSF_UPLOAD_QUEUED.

Trigger Upload Queue (CSV)

Sends valid CSV to an experiment with a bad OSF link. Expected: 202 OSF_UPLOAD_QUEUED

Trigger Upload Queue (Base64)

Sends valid base64 to the base64 endpoint with a bad OSF link. Expected: 202 OSF_UPLOAD_QUEUED

Queue Deduplication

Sends the same filename twice. Second request should not create a duplicate queue entry.

Early Persist / OOM Recovery Tests (PR #146)

Sends a large payload to trigger an out-of-memory crash in the Cloud Function. The data should be persisted to Cloud Storage (pending-data/) before the crash, and recovered by scheduledPendingRecovery within ~15 minutes. After running, check: (1) Cloud Storage pending-data/ for the persisted file, (2) after ~15 min, the uploadQueue collection in Firestore for a promoted entry, (3) the experiment dashboard QueuePanel.

Large Payload OOM (JSON)

Generates a JSON payload of configurable size and sends it. The function should persist the data before crashing.

Large Payload OOM (Base64)

Generates a large base64 payload (~33% larger in transit). More likely to trigger OOM due to decode overhead.
